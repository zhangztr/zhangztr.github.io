# 食谱田地 — 游戏设计文档

## 概述

**食谱田地** 是一款 PWA 单机生活模拟游戏。每天早上 8:00，系统随机刷新当日三餐菜单（早餐、午餐、晚餐），玩家通过种植、超市采购获取食材，自己动手做菜。游戏节奏以「天」为单位推进。

## 核心循环

```
每日菜单刷新 → 盘点已有食材 → 缺少的去种植/去超市买 → 烹饪 → 提交菜品 → 获得评价/奖励 → 第二天
```

## 菜单系统

- 每天早上 8:00 自动刷新三道菜（早/午/晚），从菜品池中按季节、难度随机抽取
- 每道菜有固定配方：所需食材及数量（如「番茄炒蛋」= 番茄×2 + 鸡蛋×2 + 盐×1）
- 每日三道菜之间有难度梯度：早餐简单、晚餐最难
- 菜单刷新后当天不变，未完成的菜可以第二天继续，但过期会扣分

## 田地系统

- 玩家拥有 N 块田地（初始 4 块，可扩展）
- 种植流程：翻土 → 播种 → 浇水 → 等待成熟 → 收获
- 不同作物有不同的生长天数（如：葱 1 天、番茄 3 天、水稻 5 天）
- 每天只能浇一次水，漏浇会延长成熟时间
- 作物有季节适应性（冬季番茄长得慢/夏季某些菜种不了）

## 超市系统

- 超市出售所有基础食材，价格浮动
- 部分稀有食材只能自己种、不能买
- 超市每天有特价商品（随机 1-3 种打折）
- 金币来源：完成菜品获得

## 烹饪系统

- 玩家在厨房中，对照当日菜单配方，投入食材完成烹饪
- 食材必须齐全才能开火
- 烹饪有成功率（基础 80%，熟练度提升或失败惩罚）
- 烹饪结果分档：完美 / 普通 / 失败（影响奖励和评价）

## 经济系统

| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 金币 | 完成菜品、出售多余食材 | 超市购物、扩展田地、购买种子 |
| 种子 | 超市购买、完成任务奖励 | 种植 |
| 食材 | 种植收获、超市购买 | 烹饪 |
| 熟练度 | 成功烹饪累积 | 提高成功率、解锁新菜品 |

## 菜谱管理

- 预设菜谱 9 道（早/午/晚各 3 道），构成初始每日随机池
- 玩家可自创菜谱：自定义菜名、餐段（早/午/晚）、食材配方、难度
- 自创菜谱的食材必须从已有物品池中选择（预设物品 + 玩家自行在超市添加的物品）
- 自创和预设菜谱平等参与每日随机抽取
- 自创菜谱可编辑和删除（删除不影响当天已刷新的菜单）
- 菜谱名不能重复

## 进度系统

- 连续完成菜单累积「连击天数」，影响金币倍率
- 完成一定数量的菜品后解锁新菜品加入随机池
- 田地可扩展（第 5 块起需要金币购买）
- 厨房可升级（提升成功率、减少食材消耗）

## 数据存储

- 所有数据保存在浏览器 localStorage
- 关键数据：金币、食材库存、田地状态、连击天数、最后登录时间
- 离线可用，无需服务器

## 技术方案

- PWA（Progressive Web App）
- 纯前端：HTML + CSS + JavaScript（无框架依赖）
- Service Worker 实现离线缓存
- manifest.json 支持手机「添加到主屏幕」
- 响应式设计，适配手机竖屏
